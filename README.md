# Niappu Companion Overlay app for MS Windows and Chrome.
Niappu Companion reads Japanese text in games and on websites so you can learn while you play. Press a hotkey, click any word on screen and get a dictionary popup with your Yomitan dictionaries. Save words, add Anki cards with a screenshot and audio, and see which words you already know from Anki, WaniKani or Bunpro. A browser extension adds the same lookups to Netflix, YouTube and any website, with a subtitle list beside the video.

It only reads what's on your screen. It never touches game memory, so anti-cheat has nothing to detect. Windows 10/11.
